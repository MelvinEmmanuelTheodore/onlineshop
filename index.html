2. How to get your Razorpay Credentials (Step-by-Step)

1
Create Free Razorpay Account: Go to razorpay.com and sign up for a business or individual account.
2
Toggle Test Mode: In your Razorpay Dashboard, toggle the switch in the top header from Live Mode to Test Mode (orange badge).
3
Generate API Keys: Navigate to Settings > API Keys > Generate Key. Copy the Key ID (starts with rzp_test_).
4
Paste Key ID Above: Paste your rzp_test_... into the input field above and click Save Key.
5
Test Checkout Flow: Add any 3D model to your cart and click Proceed to Razorpay Checkout. In the Razorpay modal, select UPI (e.g. success@razorpay) or Cards (use any Razorpay test card). Upon completion, your STL/GLB files will immediately unlock!

3. Production Architecture (For Live Stores)

For a production e-commerce store with real customer payments:

  • Backend Order Creation: Call /v1/orders from your server using your Key Secret to generate an authorized order_id.
  • Payment Signature Verification: Verify the cryptographic HMAC SHA-256 signature (razorpay_order_id + "|" + razorpay_payment_id) using your Key Secret to prevent tampering.
  • Secure Webhooks: Configure a webhook listener for payment.captured to securely dispatch one-time presigned download links.
